ABOUT THE PROJECT

A learning tool for exploring health data.

Cardio Monitor is a small machine learning demonstration. It accepts a set of heart health measurements and shows how a classifier trained on a sample dataset responds to them.

The model was created for educational exploration. Its dataset is limited, its output is only a model prediction, and it has not been evaluated for clinical use. It cannot account for a person’s complete medical history, examination, or other context.

⌁

What it uses

Thirteen structured fields, such as age, blood pressure, cholesterol, ECG category, and exercise measurements.

◉

What it returns

A binary classifier output from the included sample model. It is not a probability or a diagnosis.

⌂

How data is handled

This local demo does not save form submissions. Values are processed to produce the response page.

ⓘ
Use with care. Do not use this demonstration to make health decisions or delay care. For personal questions, speak with a qualified healthcare professional.
